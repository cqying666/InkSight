先和大家打个招呼

大家好，我做的是 InkSight——一个面向短篇小说创作者的 AI 创作教练。

起因很简单：2024 年以来短篇赛道爆发，番茄、知乎盐选、七猫、点众都在抢短篇内容，创作者大量涌入但淘汰率极高。我自己身边就有朋友写了三五篇没流量就放弃了，核心问题不是"写不出来"，而是"不知道自己差在哪里"。

市面上 AI 写作工具很多，但几乎都在替你写——续写、润色、生成大纲。我想做的恰恰相反：不替你写，而是像教练一样帮你拆解对手录像、分析战术、制定训练计划，然后看着你上场、赛后复盘。

用 TRAE 做这个项目的过程比我预想的顺畅太多。最让我惊讶的是，我只描述了"学—察—集—创—磨"这五个字的产品愿景，TRAE 就帮我把从拆文引擎到创作工作台、从趋势雷达到素材库的完整闭环全部搭建了出来。中间经历的七十几轮任务拆解，每一轮都是我提需求、它实现，配合非常默契。

1
Demo 简介

是什么：一个网页应用（Web App），短篇小说创作者的 AI 创作教练平台，构建了从拆文学习到创作实践的完整闭环。技术栈为 Next.js + SQLite + Tailwind CSS，采用"奶油炭灰"设计系统（深炭灰主色 + 暖灰褐强调色 + 奶油白背景），营造文学杂志般的克制质感。

面向谁：有写作意愿但缺乏系统方法论的中腰部短篇小说创作者——已在番茄短篇、知乎盐选等平台发表过作品，但卡在中腰部无法突破。拆文靠直觉，改进靠试错。

主要功能：

🔍 拆文分析引擎 — 三层 14 维度结构化拆解

上传任意短篇小说（支持 txt / docx / pdf 全格式），系统自动进行骨架层（开头钩子 / 三幕结构 / 反转节点 / 结局类型 / 事件密度）、血肉层（情绪曲线 / 对话比 / 感官描写 / 人物弧光 / 冲突层次）、风格层（句式 / 用词 / 视角 / 时态）的深度拆解。生成可视化"X 光片报告"——含总览卡片、情绪曲线双线叠加图、结构图谱、维度详情折叠卡。附带诊断引擎（与同类型基准数据比对，自动识别结构薄弱点）和多方向修改建议（每个薄弱点给 2-3 个方向的处方，遵循"不替写 / 不给唯一答案 / 不评判"三不原则）。

✍️ 创作工作台 — 从大纲到成稿的一站式写作

三栏布局创作环境：左侧结构大纲（可基于拆文学到的模式自动生成模板）、中间极简编辑器（自动保存 / 字数统计 / 段落编号 / 专注模式）、右侧 AI 对话面板。核心交互亮点：在编辑器空白处按空格键唤起 AI 对话，输入描述即可直接生成 200-500 字的场景文本并插入编辑器。底部实时结构提示条显示三幕进度位置、当前段落类型、距计划反转节点的距离——只提醒位置，不评价内容。支持写后一键分析：对完成的作品运行拆文引擎，生成 X 光片报告，与参考作品双篇对比。

🔄 完整创作闭环 — 学察集创磨

五个环节自动衔接，创作者不需要在多个工具间来回切换：学（拆文分析 → X 光片报告 + 诊断处方）→ 察（热门元素雷达，趋势热力图 + 题材生命周期标注 + 元素组合推荐）→ 集（三层素材库，拆文自动提取结构模式 + TF-IDF 语义搜索 + 情境匹配推荐）→ 创（创作工作台，编辑器 + 大纲 + 素材侧栏 + AI 对话）→ 磨（写后分析，对自己的作品运行拆文引擎，薄弱点转化为下一轮改进目标）。每个环节结束都有"下一步行动引导"，避免用户看完就走。

Demo 创作思路

灵感来源：2024 至 2026 年，短篇小说赛道经历了爆发式增长。番茄短篇、知乎盐选、七猫、点众等平台纷纷加码短篇内容，创作者数量快速增长，但淘汰率极高——大量新手写三五篇没流量就放弃了。核心矛盾在于：优质短篇的需求远大于供给，但创作者从入门到能产出合格作品的成长曲线太长。

想解决的问题：创作者面临四个贯穿创作全流程的痛点——

① 拆文没有系统方法：靠"感觉"拆解不可复制，拆完也不知道该怎么用

② 不知道当下什么题材有流量：盲目创作，踩不中风口

③ 素材零散存在各个文档里：用的时候找不到，也没有结构化检索

④ 写完不知道结构哪里有问题：缺乏专业编辑反馈，改进靠试错

为什么做这个方向：市面上已有不少 AI 写作工具，但存在两个结构性问题。

一是几乎全部聚焦在"帮用户写"——AI 续写、润色、生成大纲，不解决"怎么写好"的根本问题。创作者用了这些工具，文字是产出了，但结构意识没有提升，下一篇还是会犯同样的错。

二是各工具割裂——拆文工具不管创作，创作工具不管分析，素材工具不管趋势。创作者需要在多个工具间来回切换，创作流程被打断。

InkSight 的切入点是：不替创作者写，而是构建一个从拆文学习、趋势发现、素材积累到创作实践的完整闭环，让创作者在一个平台内跑完"学—察—集—创—磨"的完整一圈。教练不替你上场踢球，但他帮你分析对手录像、拆解战术、收集情报、制定训练计划，然后看着你上场、赛后复盘。

TRAE 实践过程

整个项目从零开始，使用 TRAE IDE 完成 7 个阶段、72 个任务的全流程开发。以下是完整的开发流程：

第一阶段：技术选型与管线骨架 Phase 0 · 完成

对 TRAE 描述了产品愿景（"学—察—集—创—磨"五个字的创作闭环），TRAE 帮我完成了全部基础设施搭建：

  • 技术选型：Next.js 14 + TypeScript + Tailwind CSS + SQLite（better-sqlite3）
  • 项目脚手架：路由结构、API 层、组件目录、工具库分层
  • LLM 接入层：统一客户端封装，支持多模型切换与重试控制
  • 14 维度 Zod Schema：骨架层 5 维 + 血肉层 5 维 + 风格层 4 维的强类型定义
  • 拆解 Prompt：强约束 JSON 输出，每个维度附带原文证据引用
  • 5 篇测试集：覆盖悬疑 / 言情 / 氛围 / 动作 / 混合五种类型

产出：一个能跑通的拆解管线，输入小说文本 → 输出 14 维度结构化 JSON。

第二阶段：诊断引擎与处方生成 Phase 1 · 完成

基于拆解结果，构建三步反馈管线：

  • 诊断引擎：规则引擎比对同类型基准数据，自动识别 2-3 个结构薄弱点和 1-2 个提升机会，每个诊断点附偏差百分比和严重程度评分
  • 反直觉发现：对比创作者自评与分析结果的最大偏差点，识别"创作者自己可能没意识到的结构特征"
  • 处方生成：针对每个薄弱点生成 2-3 个方向的修改建议，遵循"不替写 / 不给唯一答案 / 不评判"三不原则，每个方向附适配性评分（1-5 分）
  • 降级机制：LLM 输出异常时重试，处方超时时先展示拆解 + 诊断、处方异步加载

产出：从"拆解"到"诊断"到"处方"的完整反馈链路。

第三阶段：X 光片报告与前端界面 Phase 2 · 完成

构建四区域可视化报告页面和完整的用户交互链路：

  • X 光片报告：总览卡片（一句话总评 + 反直觉发现）、情绪曲线双线叠加可视化（标记点 + 点击跳转原文）、结构图谱、维度详情折叠卡
  • 上传页：文件拖拽上传，支持全格式（mammoth 解 docx + pdfjs-dist 解 pdf + 文本类直读 + 二进制兜底）
  • 拆解进度页：展示分析进度条（识别类型 → 分析钩子 → 绘制情绪曲线 → 生成反馈）
  • 原文联动：点击情绪曲线节点或处方段落引用，原文区自动滚动并高亮
  • 埋点系统：对齐 PRD 14 个关键事件（上传 / 分析完成 / 建议采纳 / 素材收藏等）
  • 报告导出：支持 Markdown 和 PDF 导出

产出：完整的 upload → analyzing → report 交互链路，P0 功能可演示。

第四阶段：基准库与双篇对比 Phase 3 · 完成
  • 批量拆解脚本：三模式（真实 LLM / 合成数据 / 跳过 LLM），支持批量处理 100+ 篇文章
  • 基准数据聚合：共享指标提取逻辑，聚合生成同类型基准 JSON
  • 双篇对比 UI：概览卡片 + 三幕对比条 + 19 维差异表 + 情绪曲线双线叠加 + 反转时间线对比
  • 一致性监控：5×2 测试集自动跑拆解一致性，总体一致性 96.8% 达标（阈值 >85%）
第五阶段：热门元素雷达与素材库 Phase 4 · 完成

补齐闭环的"察"和"集"两个环节：

  • 趋势热力图：题材 × 元素矩阵热力图，4 档热度色阶，支持平台筛选和时间回溯
  • 题材生命周期：四阶段算法（萌芽 / 爆发 / 平台 / 衰退），7 天增长率 + 30 天均值阈值
  • 趋势元素详情卡：热度走势 SVG 折线图 + 跨平台分布条形图 + 常见搭配 Top 5 + 一键收藏到素材库
  • 三层素材库：原子素材 / 组件素材 / 灵感素材，支持拆文自动提取 5 类结构模式
  • TF-IDF 语义搜索：N-gram 中文分词 + 余弦相似度 + 关键词降级兜底，支持类型 / 情绪 / 结构三维筛选
  • LLM 辅助标签分类：批量分类管线 + Zod 校验 + 规则版降级，题材聚类匹配 96.7% 达标
  • 合规评估：实抓 4 平台 robots.txt，完成法律风险评估，当前阶段维持 Mock-First
第六阶段：创作工作台 Phase 5 · 完成

闭环的"创"和"磨"环节，这是产品最核心的体验：

  • 编辑器内核：contentEditable 富文本 + 自动保存（30s / 失焦）+ 字数统计 + 章节分隔
  • 段落编号：CSS counter 非侵入式编号，与拆文分析段落体系一致
  • 结构大纲：空白模板 / 从拆文结果自动生成大纲模板
  • 结构参考线：左侧淡色标注三幕边界和反转节点位置
  • 实时结构提示：底部条显示三幕进度 / 当前段落类型 / 反转距离，距反转 <5% 变淡黄提示
  • 素材侧栏：主动推荐（光标位置情境检测：开头 / 反转附近 / 对话密集）+ 手动搜索 + 拖拽收藏
  • 写后分析：提取编辑器文本 → 调用拆文引擎 → 生成 X 光片报告
  • 空格唤起 AI 对话：编辑器空白处按空格，弹出输入条，支持模型选择 + 直接生成场景文本插入编辑器

产出：完整的三栏创作环境，从大纲搭建到写后分析的端到端体验。

第七阶段：闭环优化与系统加固 Phase 6 · 完成
  • 闭环仪表盘：北极星指标（月活完成闭环次数）+ 五模块指标卡 + 闭环漏斗可视化，无数据时全量展示零值
  • 个性化推荐：基于用户行为推断四阶段画像（ newcomer / learner / creator / looped），驱动拆文推荐和素材推荐
  • 鉴权系统：Cookie + JWT（jose HS256）无状态会话 + bcryptjs 密码哈希 + 角色权限（admin / experience）+ 账户管理 CRUD
  • 作品管理：作品列表 + 销售状态追踪（¥ 印章式标记已售）+ 千字单价联动计算 + 月度统计 + 筛选标签
  • AI 模型管理：可视化模型配置 + 日志查询 + 多模型切换
  • 性能优化：next/dynamic 拆分首屏体积 -49%、事件埋点 in-memory buffer + debounce、LLM 超时 30s race 包装
  • 导航断点修复：首页 → 上传 → 拆解 → 报告 → 创作 / 趋势 / 素材 / 对比 → 回首页，全链路可达
