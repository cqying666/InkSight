# Task Breakdown — InkSight 创作教练

## Overview
- Total phases: 7（Phase 0-6，对齐 PRD 第 8.2 节里程碑）
- Execution strategy: 串行为主，Phase 4 内部趋势与素材可部分并行；每个 phase 结束有可验证的交付物
- Primary dependency chain: 技术选型 → 拆文引擎骨架 → 诊断处方 → 前端报告 → 基准库+种子测试 → 趋势+素材 → 创作工作台 → 闭环优化

---

## Notes
- Highest-risk phase: Phase 0（LLM 一致性决定后续一切）+ Phase 4（合规风险决定趋势模块能否上线）
- First executable task: P0-T1（技术选型决策文档）— 所有后续任务的前置
- 关键决策点：技术选型完成后需用户确认再进入 P0-T2 脚手架搭建
