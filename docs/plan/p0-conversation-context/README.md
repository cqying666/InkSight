## 4. 预算结论怎么理解

服务接口实际返回deepseek-flash，官方表称其当前窗口1M；P0没有把这个声明当作百万Token压测通过。

产品不必每次填满服务窗口。建议49,152 Token作为后续试行工作窗口：观测输入峰值32,532＋内容输出预留6,000＋误差余量1,024＋增长预留4,096＝43,652；49,152可覆盖这一基线，并比65,536更小。

这是一份有测量来源和限制说明的预算候选，尚未生效，也未证明最优。S/G仍需长请求校准；现有32,768配置和42,000字符限制均未修改。
