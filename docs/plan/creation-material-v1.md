# 素材转核心梗与框架 V1

日期：2026-09-15。依据 creation-agent-product-consensus.md 与原 V1 PRD，本次用户授权直接实施。

## 目标与边界
作者从文字素材中选定值得继续写的故事核与结构方向。复用 /creation、Pi、SQLite、工作记忆、方向家族版本和选定/保存/工作台；不生成完整章节大纲或正文。

## 契约
- 任务解析增加 material 类型，逐字绑定输入资料；多片段明确组合/一组/备选，未知时询问。文件与文本长度不决定意图。
- CreationDirection 增加可选 material 对象；旧二创字段保留。同一 directions 动作按本轮任务或父版本选择生成契约，不需要拆解报告。
- material 保留来源版本、素材价值、作者明示设定、主角欲望/阻力/代价、关键选择、保留/改变、新增设定，以及框架适配理由/条件/不足/取舍/简短推进链。
- 框架引用只能来自本轮实际检索，系统建议明确标注；每次修订重新检索并生成适配说明。框架并非完整章节模板。
- 默认三个，明确指定数量遵循 1—5；修订单个版本只产生一个版本。交付检查禁止自由文本代替候选。
- 硬约束冲突交由作者确认；选定不自动保存作品；版本成果及知识快照一起持久化。

## 验收清单
1. 素材直接生成且无伪造报告；文件无目标询问。
2. 原始叙述、作者虚构、新增设定分开，来源逐字与版本可查。
3. 候选实质差异、冲突持续、主角选择/代价；默认3个。
4. 框架可追溯、前提/局限/取舍齐全，无匹配时说明；修订重新匹配。
5. 聚焦/比较/新版本/选定/保存/恢复/幂等工作台完整。
6. 隔离、停止、重试、超限、模型/保存失败与旧数据回归。
7. 类型/构建/浏览器及职场、亲情、婚恋、脑洞真实样例；分别记录工程与人工文学验收边界。
