# P4-T2 采集合规评估报告

> **任务**：P4-T2 趋势数据采集合规评估（robots.txt + 反爬政策 + 法律评估）
> **状态**：已完成
> **评估日期**：2026-07-03
> **评估范围**：番茄短篇、知乎盐选、七猫、点众 4 个平台公开榜单元数据采集
> **关联**：工程约束 §1.2 数据采集合规 / PRD §5.5 平台数据采集 `[待评估]` / P4-T1 mock 采集器

## 1. 评估背景与采集范围

InkSight 热门元素雷达模块（PRD §5.5）需要每日 1 次采集 4 个平台的公开榜单数据，结构化存储以下字段：

| 数据字段 | 来源 | 是否正文 |
|----------|------|----------|
| 作品标题、作者、平台 | 各平台公开榜单页 | 否 |
| 题材标签（悬疑/言情/治愈/复仇/重生…） | 平台标签 + LLM 辅助分类 | 否 |
| 热度值（阅读量/点赞/评论数/收藏数） | 各平台公开数据 | 否 |
| 榜单排名变化 | 与前一日对比 | 否 |

**采集边界（硬约束）**：
- 仅采集公开榜单页面信息，**不采集付费内容正文**
- 数据用于趋势统计分析，**不存储和展示单篇作品完整内容**
- 采集频率：每日 1 次（低频）
- 用途：聚合趋势分析，非内容搬运

本评估基于上述边界判断直采合规性，并为不合规平台提供替代方案。

## 2. 各平台合规评估

### 2.1 番茄短篇（fanqienovel.com，字节跳动旗下）

#### A. robots.txt 分析

实际抓取 `https://fanqienovel.com/robots.txt`：

```
User-agent: *
Allow: /
```

- **结论**：全站对通用爬虫开放，未设置 Disallow 路径，榜单页在技术上未被 robots.txt 禁止。
- **Crawl-delay**：未设置。
- **限制**：无显式限制，但仍受服务条款约束。

#### B. 反爬政策

- **技术反爬**：榜单页 `/library/rank/most_read` 等为 JS 渲染（WebFetch 返回"暂无内容"），需 Playwright/headless 浏览器执行 JS 才能拿到完整 DOM；字节系普遍部署设备指纹 + 频率限流。
- **服务条款**：番茄小说用户协议页（/help/agreement）未在本次抓取中返回完整协议原文（页面可能为 SPA 动态加载），但字节跳动系产品用户协议通常包含"禁止使用自动化手段采集"通用条款。
- **公开 API**：无面向第三方的公开榜单 API。

#### C. 法律风险

- **风险等级：低-中**
- robots.txt 全站开放降低了技术合规风险；
- 但 JS 渲染 + 设备指纹表明平台不鼓励程序化访问，绕过 JS 渲染可能被视为"突破技术保护措施"；
- 作者笔名属于《个人信息保护法》第 4 条定义的个人信息（可识别自然人），需脱敏或最小化存储；
- 聚合统计用途 + 不存储正文，显著降低不正当竞争风险。

#### D. 替代方案

1. **首选：商务授权**——与番茄小说商务团队接洽，申请榜单数据合作授权（官方 API 或数据包）；
2. **次选：Playwright 日 1 次采集**——在 robots.txt 允许前提下，用 headless 浏览器渲染榜单页，仅提取标题/作者/标签/热度字段，遵守频率限制（≤1 次/日），缓存 24 小时；
3. **降级**：维持当前 mock 采集器（P4-T1）直到合规通道建立。

### 2.2 知乎盐选（zhihu.com 付费故事专栏）

#### A. robots.txt 分析

实际抓取 `https://www.zhihu.com/robots.txt`：

```
User-Agent: *
Allow: /tardis/jm
Disallow: /
```

- **结论**：通用爬虫（`*`）**全站禁止**，仅放开 `/tardis/jm` 路径。盐选榜单页路径（如 `/market/...`、`/zhuanshu/...`）在 Disallow 范围内。
- **限制**：robots.txt 层面已明确禁止榜单页采集。

#### B. 反爬政策

- **服务条款原文**（2025-03-20 更新版，WebFetch 抓取自 https://www.zhihu.com/term/zhihu-terms）：
  - 第二章第 9 条 a 款：禁止"使用任何自动化程序、爬虫、蜘蛛等"访问知乎；
  - 第二章第 9 条末项：禁止"爬取、抓取、复制"知乎内容；
  - 第三章第 10 条：禁止将知乎内容"用于商业目的"或"AI 训练"。
- **技术反爬**：登录墙（盐选内容需登录）、验证码（极验滑块）、IP 频率限流、设备指纹、请求头校验（Referer/Cookie 严格）。
- **公开 API**：无面向第三方的盐选榜单 API。

#### C. 法律风险

- **风险等级：高**
- robots.txt 明确 Disallow + 服务条款明文双重禁止，直采属于违反平台规则；
- **已有刑事判例**：知乎盐选李某、毛某两起爬虫盗用案已判刑，确立"非法获取计算机信息系统数据罪"适用先例；
- 民事判例参考：微信公众号爬取判赔 300 万、淘宝天猫爬取判赔 500 万；
- 即使仅采集元数据（不采正文），违反 robots.txt + 服务条款已构成"不正当竞争"基础；
- 2025《反不正当竞争法》第 13 条第 3 款（2025-10-15 施行）数据不正当竞争专款进一步加重责任。

#### D. 替代方案

1. **首选：放弃直采**——知乎盐选在 robots.txt + 服务条款 + 判例三重禁止下，不进行任何程序化采集；
2. **次选：商务授权**——与知乎盐选团队接洽内容数据合作（难度高，知乎对盐选数据保护严格）；
3. **可行替代：人工录入**——运营人员每日人工浏览盐选榜单，手工录入标题/作者/标签到后台（不涉及程序化抓取，但效率低）；
4. **可行替代：用户授权导入**——用户主动分享自己阅读记录或截图，OCR + LLM 提取结构化数据（用户授权路径，参考最高法指导案例 263 号"经用户授权转移数据"合法路径）；
5. **降级**：维持 mock 数据，前端在知乎盐选列标注"数据待合规接入"。

### 2.4 点众（dianzhong.com）

#### A. robots.txt 分析

实际抓取 `https://www.dianzhong.com/robots.txt`：

```
User-agent: *
Allow: *
```

- **结论**：全站对通用爬虫开放。
- **限制**：无显式限制。
- **问题**：点众主流量在 App（dianzhong App），Web 端榜单页内容可能不全或为旧版，robots.txt 开放但 Web 端数据价值有限。

- **服务条款**：App 内用户协议需 App 内访问，未在本次抓取中获取原文；

1. **首选：放弃 Web 直采（数据价值不足）+ 商务合作**——点众 Web 端榜单可能不全，建议与点众商务接洽数据合作；

## 4. 统一合规建议

### 4.1 采集原则（适用于所有平台）

1. **仅采公开榜单元数据**——标题/作者/标签/热度/排名，**绝不采集正文**；
2. **低频采集**——每日 ≤1 次，遵守 Crawl-delay（如设置）；
3. **聚合统计用途**——数据用于趋势分析，不展示单篇完整信息；
4. **最小化存储**——作者笔名脱敏或哈希存储，不建立"作者-作品"可识别档案；
5. **缓存 + 降级**——采集结果缓存 24 小时，失败时降级到旧数据（P4-T16 已实现）；
6. **User-agent 透明**——使用可识别的 UA（如 `InkSightBot/1.0 (trend-research; contact@inksight.example)`），不伪装浏览器；
7. **可追溯**——每次采集记录时间戳 + 平台 + 字段范围，便于合规审计。

### 4.2 分阶段接入策略

**Phase 4 当前阶段（Mock-First）**：
- 维持 P4-T1 mock 采集器（LCG PRNG 可复现），趋势模块前端已跑通；
- 不进行任何真实采集，等待合规通道建立。

**下一步（合规接入）**：
1. **优先接入七猫**（风险最低）——直接技术采集 `/paihang`，验证采集管线；
2. **次选接入番茄**（风险低-中）——先用 Playwright 试采，同步发起商务授权接洽；
3. **点众**——启动商务合作接洽，Web 端数据不全则维持 mock；
4. **知乎盐选**——放弃直采，启动商务授权接洽；同步开发"用户授权导入"功能作为长期替代。

### 4.3 替代数据源（不依赖直采的长期方案）

1. **第三方数据服务商**——如七麦数据、蝉大师、酷传等 App 榜单聚合服务，已与各平台有数据授权，InkSight 可采购其 API；
2. **用户授权导入**——用户主动分享阅读记录/截图，OCR + LLM 提取结构化数据（参考最高法指导案例 263 号"经用户授权转移数据"合法路径）；
3. **官方商务合作**——与各平台商务团队接洽，申请榜单数据合作授权；
4. **人工录入**——运营人员每日人工浏览榜单，手工录入后台（效率低但 100% 合规）。

### 4.4 法律合规框架参考

| 法规/判例 | 要点 | 对本项目影响 |
|-----------|------|--------------|
| 《网络安全法》 | 网络运营者收集数据需合法、正当、必要 | 仅采公开元数据，符合"必要"原则 |
| 《数据安全法》 | 数据处理需建立数据分类分级保护制度 | 需建立采集数据分类台账（元数据 vs. 正文） |
| 《个人信息保护法》第 4 条 | 个人信息 = 以电子方式记录的与已识别或可识别自然人有关的信息 | 作者笔名属个人信息，需脱敏/最小化存储 |
| 《反不正当竞争法》第 13 条第 3 款（2025-10-15 施行） | 数据不正当竞争专款 | 不存储正文 + 聚合用途降低竞争损害 |
| 最高法第 47 批指导性案例 262-267 号（2025-08-28） | 确立数据抓取合法边界；263 号确立"经用户授权转移数据"合法路径 | 用户授权导入功能有判例支撑 |
| 知乎盐选李某/毛某刑事案 | 爬取盐选内容判"非法获取计算机信息系统数据罪" | 知乎盐选不可直采 |
| 微信公众号爬取案（判赔 300 万） | 民事赔偿先例 | 即使不涉刑责，民事赔偿风险存在 |

## 5. 评估结论与门禁解除建议

### 5.1 评估结论

- **4 平台中 1 个高风险（知乎盐选）、1 个低-中风险（番茄）、1 个低风险（七猫）、1 个 Web 端低风险但数据价值不足（点众）**；
- **InkSight 当前 Mock-First 策略合规**——未进行任何真实采集，无合规风险；
- **真实采集接入需分平台差异化处理**——七猫可直采，番茄需 Playwright + 商务接洽，点众需商务合作，知乎盐选放弃直采。

### 5.2 工程约束 §1.2 门禁解除建议

工程约束 §1.2 要求"上线前需完成各平台 robots.txt 和反爬虫政策评估"——**本评估已完成**。

**门禁解除条件**：
1. ✅ 本评估文档落档（已完成）；
2. ⏳ 真实采集器接入前，需为每个平台单独签署合规确认（商务授权协议 OR 内部合规复核记录）；
3. ⏳ 趋势模块对外上线前，需完成采集数据分类台账 + 用户授权导入功能（针对知乎盐选/点众）。

**当前阶段**：评估完成，趋势模块仍维持 Mock-First，**不对外上线真实采集数据**，门禁在"真实采集器接入"节点前保持。
