# 验收标准

- [x] 首页显示闭环北极星、五阶段进度与模块摘要，原有问候、输入和场景卡继续可用。
- [x] 侧栏不再提供重复的闭环仪表盘菜单，旧 `/dashboard` 页面仍可访问。
- [x] 真实拆文报告默认不保存素材，用户可按剧情、人设、情绪分类多选，并选择或新建文件夹。
- [x] 同一报告候选使用稳定 ID，重复确认执行更新而非新增副本。
- [x] 演示报告不能写入个人素材库。
- [x] 素材库可新建人设、剧情、情绪描写语录和灵感素材，支持标题、内容、标签和文件夹。
- [x] 新建素材保存后立即显示在正确分类，刷新后仍存在，并可被工作台素材库与 AI 读取。
- [x] 正文、对标文、大纲、细纲、人物小传均有真实内容来源；对标文和人物小传可从最新拆文结果播种。
- [x] AI 引用选择器可同时选择最多八项文档或素材，并在发送前显示可移除的引用标签。
- [x] AI API 校验消息角色、引用类型、数量和长度；引用内容被明确标记为资料而非系统指令。
- [x] 编辑器支持手动与自动保存、保存失败提示、撤销、重做、二级标题、列表、删除线、清除格式、章节、分隔线和纯文本粘贴。
- [x] 素材插入正文后会触发字数、脏状态与保存链路更新。
- [x] 首页闭环指标接受实际 `upload_submitted` 事件，并按事件时间顺序判断闭环。
- [x] TypeScript 检查与生产构建通过。
- [x] 素材库首项显示为「例文」，不再把全部素材混入该入口。
- [x] 例文卡片展示书名、原文前三句话、题材、标签和已拆文状态。
- [x] 用户可在素材库直接上传例文而不触发拆文，保存失败时保留表单并提示。
- [x] 从拆文入口上传的作品会先进入例文库，拆文成功后在同一记录补齐报告、题材和标签。
- [x] 已拆文卡片进入对应 X 光报告并默认打开原文；仅上传卡片进入纯原文页。
- [x] 纯原文页提供继续拆文入口，完成后可升级为已拆文例文。
- [x] 例文列表只传输摘要，完整原文和分析报告仅在点击详情时读取。

## 首页意图路由与导语二创

- [x] “拆解这篇全文”加全文内容进入完整拆文，不进入导语管线。
- [x] “只分析这段导语”进入纯导语分析，不强制生成二创方向。
- [x] “分析导语并给二创/仿写方向”进入导语二创模式，并先从混合输入中分离真实导语。
- [x] 自然语言“生成/写几个导语”继续进入导语生成，不被识别为导语分析。
- [x] 上传文件未指定特殊意图时保持默认全文拆文；上传导语并明确要求二创时进入导语二创。
- [x] 导语二创输出包含核心元素、3—5 个差异化方向、推荐方向与避雷说明；不得照搬专属人物、数字和表达。
- [x] 导语报告仅在二创模式展示核心元素和二创模块，纯分析模式保持精简。
- [x] 意图路由与导语输出协议有确定性合同测试；TypeScript 和生产构建通过。
