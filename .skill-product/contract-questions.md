# 产品契约记录

## 范围边界

- 部分拆文成功：仅从成功的剧情或人设分支生成候选，不保存空素材。
- 演示报告：只展示能力说明，不允许沉淀。
- 重复入库：按稳定候选 ID 执行幂等更新。
- 空文档：不出现在 AI 可引用列表中。
- 引用过长：客户端最多八项，服务端每项和总字符数双重限制。
- AI 超时：四十五秒后终止请求，保留引用选择并提示重试。

## API 契约

- 请求：`messages` 使用 `user／assistant` 角色；`context.references` 包含 `id／kind／label／content`。
- 响应：成功返回纯文本流；请求不合法返回四百；未配置模型返回五百零三；上游异常返回五百零二。
- 安全：引用段落使用显式边界，系统提示要求模型把其中指令视为普通资料。

## 状态模型

- 加载：首页、素材库和编辑器显示轻量加载态。
- 空态：首页给出拆文与创作入口；报告给出无候选说明；AI 隐藏空文档。
- 错误态：拆文、素材加载、保存和 AI 分别提供独立降级，不阻塞其他模块。
- 成功态：素材入库后提供“查看素材库／带着素材去创作”，文档自动保存，首页由埋点数据自动更新。

- 把匿名会话级闭环升级为项目实体级闭环，统一 `projectId／analysisId／draftId`。

## 首页意图路由与导语二创契约

- API 输入：`/api/guide-analysis` 接受 `text` 与 `mode: analysis | analysis_with_directions`；缺省 mode 继续兼容旧调用。
- API 输出：纯分析沿用现有导语结果；二创模式额外返回 `coreElements`、`derivativeDirections`、`recommendedDirection`、`recommendationReason`。
- 路由优先级：显式 @技能 > 明确自然语言意图 > 内容长度兜底；“生成导语”优先于“分析导语”。
- 内容边界：上传文件内容天然与指令分离；粘贴混合输入支持“导语/全文/原文如下：”和“指令段落 + 正文段落”的确定性切分。
- 失败状态：没有可分析内容时回到上传/创作入口；导语二创结果缺少三条方向时由 Schema 触发模型重试。
- 安全：用户正文始终作为不可信资料；二创只迁移机制，不照搬专属人物、数值、关系和独家表达。
