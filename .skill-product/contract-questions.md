# 产品契约记录

## 范围边界

- 部分拆文成功：仅从成功的剧情或人设分支生成候选，不保存空素材。
- 演示报告：只展示能力说明，不允许沉淀。
- 重复入库：按稳定候选 ID 执行幂等更新。
- 空文档：不出现在 AI 可引用列表中。
- 引用过长：客户端最多八项，服务端每项和总字符数双重限制。
- AI 超时：四十五秒后终止请求，保留引用选择并提示重试。

## API 契约

- 请求：`messages` 使用 `user／assistant` 角色；`context.references` 包含 `id／kind／label／content`。
- 响应：成功返回纯文本流；请求不合法返回四百；未配置模型返回五百零三；上游异常返回五百零二。
- 安全：引用段落使用显式边界，系统提示要求模型把其中指令视为普通资料。

## 状态模型

- 加载：首页、素材库和编辑器显示轻量加载态。
- 空态：首页给出拆文与创作入口；报告给出无候选说明；AI 隐藏空文档。
- 错误态：拆文、素材加载、保存和 AI 分别提供独立降级，不阻塞其他模块。
- 成功态：素材入库后提供“查看素材库／带着素材去创作”，文档自动保存，首页由埋点数据自动更新。
