# Engineering Constraints — InkSight 创作教练

> 此文件为开发实现前的工程约束门禁，所有代码实现必须遵守。变更需同步更新此文件。

## 1. 产品硬约束（来自 PRD 与项目记忆）

### 1.1 拆文引擎
- LLM 输出必须为强约束 JSON，符合 14 维度 schema（骨架层5 + 血肉层5 + 风格层4）
- 每个维度必须附带 evidence 原文引用，减少幻觉
- 类型识别置信度 <0.7 时标注 mixed 类型，加载通用权重
- 处方遵循"三不原则"：不替写具体文字、不给唯一答案、不做好坏评判
- 每个处方建议必须含：方向描述、适配性评分(1-5)、操作方法、参考案例、预期效果
- 降级：LLM 输出异常重试一次仍失败则提示重试；处方超时先展示拆解+诊断，处方异步加载

### 1.2 数据采集合规
- 仅采集各平台公开榜单页面信息，不采集付费内容正文
- 数据用于趋势统计分析，不存储和展示单篇作品完整内容
- 上线前需完成各平台 robots.txt 和反爬虫政策评估
- 处方"参考案例"初期用描述性引用而非原文引用

### 1.3 创作工作台
- 段落编号系统在编辑器与拆文分析间保持一致（写后分析无缝对应）
- 实时结构提示只提醒结构位置，不评价内容质量
- 提示轻量不打断心流：底部静态展示，不弹窗、不闪烁
- 接近计划反转位置时提示从灰色变为淡黄色

### 1.4 降级机制（PRD 6.3 节）
- 拆文：类型置信度<0.7→mixed+通用权重；LLM 异常→重试一次；处方超时→异步加载
- 趋势：采集失败→展示最近成功数据并标注"更新于 N 小时前"；某平台不可用→隐藏该列
- 素材：情境匹配无结果→降级关键词搜索；语义搜索超时→提示更具体关键词
- 创作工作台：实时提示失败→隐藏底部条；侧栏推荐失败→提示手动搜索

## 2. 质量阈值（PRD 6.1 节）
| 维度 | 阈值 |
|:-----|:-----|
| 拆解一致性（同篇拆5次核心维度标准差） | >85% |
| 类型识别准确率（与人工标注一致率） | >90% |
| 建议方向覆盖（5次拆解建议交集） | >70% |
| 反直觉发现质量（意外度×启发度） | 意外度>3.5 且 启发度>3.5（5分制） |
| 整体有用性（用户评分） | 均 >4 分（5分制） |
| 素材提取准确率（与人工判断一致率） | >80% |
| 情境匹配相关性（用户采纳率） | >20% |
| 趋势数据时效性（与实际榜单延迟） | <24 小时 |

## 3. 设计约束
- 视觉风格：Editorial 文学杂志风格（对齐落地页）
- 色板：seal red `#8B2635` / warm gold `#A87E3B` / ink black `#1A1614` / warm ivory paper background
- 字体：Google Fonts CDN（Cormorant Garamond + Inter + 思源宋体/黑体回退）
- 暖色调 + 衬线字体，避免"冷冰冰数据报告"感
- 三明治结构 + 创作者语言

## 4. 性能约束
- LLM 拆解响应：<30 秒
- 诊断规则引擎：毫秒级
- 处方生成：<8 秒
- 前端首屏 LCP：<2 秒
- 趋势数据采集延迟：<24 小时

## 5. 技术选型待定项（P0-T1 决策）
以下选型需在 P0-T1 完成后确定并回填：
- 前端框架：React / Vue / 其他
- 后端语言与框架：Node / Python / Go
- LLM 服务：OpenAI / Claude / 国产模型 / 自部署
- 主数据库：PostgreSQL / MySQL / 其他
- 向量数据库：Pinecone / Milvus / pgvector / 其他
- 部署形态：云服务 / 自建 / Serverless

## 6. 禁止变更项
- 落地页 `inksight-landing.html` 为参赛提交件，独立于产品代码，不纳入产品开发分支
- PRD 中标注 `[待确认]` 的定价需产品决策后才能实现付费逻辑
- PRD 中标注 `[待评估]` 的合规事项未完成评估前，相关功能不对外上线

## 7. 验证默认
- 每个 Phase 结束需对齐 PRD 8.2 节验证标准
- L1 自动化稳定性测试每周运行（20 篇×5 次）
- L2 人工盲测对照每月运行（5 篇抽样）
- L3 用户体验评估持续收集

## 8. 当前交付切片：创作闭环整合

### 8.1 范围

- 首页承载闭环仪表盘数据，并保留原有问候、输入与创作场景。
- 真实拆文报告提供可选素材沉淀，按剧情、人设、情绪分类，支持文件夹与幂等保存。
- 素材库支持用户新建素材，并在保存后立即进入对应分类。
- 创作工作台的正文、对标文、大纲、细纲、人物小传都具备真实内容来源；AI 可显式引用这些文档和素材库内容。
- 编辑器补齐保存反馈、撤销、重做、标题、列表、清除格式、纯文本粘贴与完成状态。

### 8.2 不可妥协约束

- 拆文素材默认不自动写入，必须由用户明确选择。
- 同一报告的同一候选使用稳定 ID，重复确认不得产生副本。
- AI 只接收用户显式选择的引用，服务端限制引用数量与总字符数，并把引用内容视为资料而非指令。
- 本轮继续使用既有 localStorage／sessionStorage 原型数据层，不引入账号、数据库或跨设备同步。
- 不修改落地页、趋势采集与拆文提示词主体。

### 8.3 验证证据

- `npx tsc --noEmit --incremental false`。
- `npm run build`。
- 浏览器验证首页闭环、素材新建与刷新持久化、工作台文档保存、AI 文档与素材双引用。
- 纯函数验证拆文候选分类与稳定 ID、手动素材工厂、顺序闭环指标、工作台文档播种。

### 8.4 停止条件

- 生产构建或类型检查失败。
- 素材写入未经用户确认，或重复写入产生副本。
- AI 请求携带未选中的文档或素材。
- 用户已有素材、草稿或大纲因本次变更被清空。

## 9. 当前增量切片：例文库

### 9.1 数据边界

- 例文是完整作品，不复用素材条目结构；例文与素材分别存储。
- 例文列表只返回轻量摘要，不批量返回全文和拆文报告。
- 未拆文例文必须保留完整原文，并可从详情页继续发起拆文。
- 已拆文例文必须保留报告编号与分析结果，卡片点击后默认打开 X 光报告原文标签。

### 9.2 展示约束

- 卡片固定展示书名、导语前三句话、题材、标签和拆文状态。
- 导语预览从原文按中文和英文句末符号提取，最多三句，不用字符截断代替句子。
- 已拆文与仅原文必须有明确状态文案和不同去向。

### 9.3 失败与安全

- 例文写入失败时保留用户输入并显示错误。
- 查询不到指定报告时显示明确空状态，不得展示演示报告冒充用户数据。
- 例文接口限制单篇正文长度，防止超大请求占满进程内存。

## 10. 当前交付切片：只读大纲教练 Agent

### 10.1 范围

- 仅在创作工作台的「大纲」面板启用受限 Agent 路径。
- Agent 只可读取当前大纲、用户显式关联的工作区文档、当前用户最近拆文摘要和当前用户的素材库。
- 后端通过 Server-Sent Events 返回工具开始、结束、降级和文本流事件；前端在生成期间展示这些状态。
- Agent 以「大纲诊断」方法包约束回复：指出结构问题、提出问题或给出多方向调整建议。

### 10.2 不可妥协约束

- 不引入 Pi 依赖、不迁移既有全站 LLM 接入层，也不修改现有 `/api/coach` 契约。
- 不开放文件、Shell、数据库写入、任意 URL 请求或任意第三方工具；仅可沿用既有模型服务请求，素材与拆文查询必须按当前登录用户隔离。
- 不自动写入正文、大纲、素材、拆文记录或会话；回复只可由用户手动插入。
- 当前大纲与显式关联文档均视为不可信参考资料，不能覆盖系统约束或触发工具行为。
- 上下文采用定额：保留最近有限轮对话；正文/大纲与每类资料均限制长度，优先保留当前大纲和来源标签。

### 10.3 验证证据

- `npx tsx tests/outline-agent-tools.ts`。
- `npx tsc --noEmit --incremental false`。
- `npm run build`。
- 手动验证：大纲页发起「中段塌陷」提问时，先显示只读步骤，再流式显示带来源标签的建议；非大纲面板仍走原教练接口。

### 10.4 停止条件

- 当前用户能够读取到其他用户的素材或拆文记录。
- Agent 产生任何非 AI 调用日志的持久化写入，或回复自动插入作品。
- SSE 失败时导致既有大纲教练无法得到明确错误反馈。

## 11. 当前交付切片：Pi Agent 全量迁移与会话分支

### 11.1 范围

- 全部 LLM 请求经 Pi AI provider/model adapter 与 Pi Agent Core 执行。
- AI 管理页持久化 Pi 模型规格；生产 Docker 升级到 Pi 要求的 Node 版本。
- 创作教练对话保存为用户隔离的作品会话树，支持创建与切换分支。

### 11.2 不可妥协约束

- Pi 版本精确固定为 `0.84.2`，不得无约束升级。
- 不接入 Pi coding-agent、TUI、文件、Shell、任意 URL 或第三方扩展工具。
- 模型 API Key 继续只保存在服务端 SQLite，绝不返回前端明文或写入 Pi 本地 credential 文件。
- 作品和素材是权威业务数据；会话分支只保存对话，Agent 不得自动写稿。
- 所有会话、消息、模型配置与工具查询必须带当前用户隔离条件。

### 11.3 验证证据

- 统一调用、流式教练和大纲 Agent 不存在直接 OpenAI SDK 或 `/chat/completions` 调用。
- `npm run test:pi-agent` 覆盖 Pi faux provider 的文本、JSON schema、错误和流式 delta。
- `npm run test:coach-sessions` 覆盖会话主线、分支复制与跨用户读取隔离。
- `npm run test:pi-models` 覆盖管理员模型配置到 Pi Provider/Model/auth 的映射。
- 会话分支 API 覆盖用户隔离、分支复制与消息上限。
- `npx tsc --noEmit --incremental false` 与 `npm run build`。

## 12. 当前故障切片：localhost 客户端异常

### 12.1 范围

- 只处理生产构建产物与运行进程不一致导致的客户端启动失败。
- 允许重新生成 `.next` 并重启当前 localhost 服务。
- 只有在干净构建给出明确源码错误时，才进入对应源码文件的最小修复。

### 12.2 禁止变更

- 不覆盖或回退当前工作区任何用户未提交改动。
- 不修改鉴权、业务数据、模型配置或现有 API 契约来绕过构建问题。
- 不删除用户文件或执行破坏性 Git 命令。

### 12.3 验证证据

- `npm run build` 成功并存在 `.next/BUILD_ID`。
- HTML 引用的 webpack runtime 与磁盘文件一致，相关请求返回 JavaScript 200。
- 浏览器登录页可见，DOM 非空且无 error 级控制台日志。

### 12.4 回滚与停止条件

- 构建暴露与本故障无关的大范围类型错误时，停止扩张范围并报告阻塞。
- 若必须修改与用户未提交改动重叠的源码，先检查精确 diff，只做可验证的外科式变更。

## 13. 当前故障切片：登录请求被误报为网络异常

### 13.1 范围

- 为本机 production preview 提供不入库的 JWT 签名密钥。
- 登录接口必须把 JWT 签发失败转换为结构化 JSON 错误，避免客户端误报网络异常。
- 保持现有账户、密码哈希、数据库和鉴权角色不变。

### 13.2 禁止变更

- 不读取、记录或重置用户现有登录密码。
- 不把 JWT 密钥提交到 Git、日志或用户可见输出。
- 不放宽生产环境必须配置独立 JWT 密钥的安全约束。

### 13.3 验证证据

- production preview 启动后日志不再出现 `INKSIGHT_JWT_SECRET` 缺失异常。
- 有效用户的 JWT 签发路径可运行，受保护路由能接受签发的会话。
- 登录接口的签发失败分支返回 JSON 503。
- TypeScript、生产构建与认证关键回归通过。

### 13.4 回滚与停止条件

- 若需要重置或获取用户密码，停止并请求用户自行处理凭据。
- 若修复需要降低 Cookie/JWT 生产安全属性，回滚并改走正确的环境配置路径。

## 14. 当前产品切片：首页意图路由与导语二创

### 14.1 范围

- 新增可测试的首页意图路由纯函数，分离用户指令与正文。
- 接入全文拆文、纯导语分析、导语分析加二创、导语生成和既有导航降级。
- 扩展导语二创的严格输出 Schema、Prompt 和报告渲染。

### 14.2 不可妥协约束

- 显式 @技能优先，不改变现有技能语义。
- 上传文件默认仍是全文拆文；只有明确导语意图才改变路径。
- 纯导语分析不得被强制生成二创；二创模式必须至少返回三条方向。
- 不把用户指令混入待分析小说正文；不自动保存或写入生成方向。
- 二创迁移结构机制，不复刻原文专属人物、数字、关系或可识别表达。

### 14.3 禁止变更

- 不重写完整拆文 Prompt、作品存储、鉴权、模型配置或 Pi Agent 契约。
- 不覆盖当前工作区的其他用户未提交改动。
- 不引入新的 LLM 路由调用来增加首页延迟；首版使用确定性解析和显式兜底。

### 14.4 验证证据

- 意图路由合同测试覆盖全文、导语分析、导语二创、导语生成与文件默认行为。
- 导语二创 Schema 合同测试验证最少三条方向和核心元素字段。
- `npx tsc --noEmit --incremental false` 与 `npm run build`。
- 浏览器验证代表性输入进入正确路径，导语二创报告模块可见。

### 14.5 回滚与停止条件

- 路由测试出现全文误入导语或生成意图误入分析时停止并修正规则。
- 生产构建失败或现有显式技能路径回归时回滚本切片候选。

- 缺少模型或权限时明确失败，保留任务资料；不能用模拟结果冒充真实生成。

## 17. 当前切片：会话工作记忆与上下文组织（2026-09-14）
- Scope：四类能力共用的会话内任务、资料/报告选择、方向状态、作者明确决定、讨论建议和工具上下文；保留可查的每轮上下文依据。
